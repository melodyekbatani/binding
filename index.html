On type

Melody Ekbatani

On type is structured as a book translated into a digital format. It brings together three texts Typography Is a Grid, Castles Made of Sand, and This Is Auto-Tune Typography and treats each one as a chapter within a single, shared system. The site is built on a consistent editorial framework. The grid, page structure, navigation, and hierarchy remain fixed across all pages, while small shifts in typographic behaviour respond to the ideas within each text. Instead of redesigning each reading from scratch, this project explores what happens when one system is applied repeatedly, and how meaning emerges through use, variation, and restraint.

Typography here is treated as a decision-making tool rather than a stylistic layer. Across the three chapters, the system moves between moments of structure, instability, and automation—echoing the arguments of the texts themselves. Some pages feel controlled, others slightly unresolved or repetitive, reflecting how design systems can clarify ideas, reveal their limits, or quietly flatten them.

The website includes a homepage that functions as a cover, navigation that acts as a table of contents, individual pages for each text, and this colophon as an introduction. It is designed to be responsive across desktop, mobile, and print formats, with an emphasis on readability, pacing, and continuity. This project is an exercise in designing with intention: paying attention to defaults, resisting unnecessary variation, and asking how typography shapes not just how text appears, but how it is experienced over time.
